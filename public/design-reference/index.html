01 / Global style settings

Content width: 1120px with 40px desktop side padding; 24px on mobile. Heading font: Georgia, regular. Body font: Arial, 15px, line height 1.7. Desktop H1: 70px; H2: 43px; H3: 25px. Mobile H1: 54px; H2: 34px. Eyebrows: Arial bold, 10px, 2px letter spacing. Text: #293F36; secondary text: #68736C. Buttons: 13px, 15px vertical and 25px horizontal padding, 3px corner radius. Section spacing: 85px desktop / 55px mobile.

03 / Images and content

Use your original logo from logo.jpg. The wordmark above is a typographic layout reference. Existing images: bakes.jpg, menu.jpg and community.jpg. These files are collages; the reference uses CSS cropping. For the WordPress build, upload individual original photos wherever possible, then match these crops. Product prices and pack sizes come from the current project and should be confirmed before launch.

04 / Other pages and links

Menu page: reuse the header and footer, add a centered title and category anchor links, then repeat the product cards under each category. Product detail: photo left, title, description, pack price and message-to-order button right; stack on mobile. Contact page: short ordering introduction, Instagram and Facebook buttons, and the three ordering steps. Keep ordering message-based to match the current site. The category links in this reference open the supplied menu image; replace them with the matching sections on your WordPress menu page.

05 / Responsive and finishing checks

Use 900px and 640px as the design’s tablet and mobile breakpoints, or map these layouts to your configured breakpoints. Check at 1440px, 768px and 390px. Keep buttons comfortably tappable, photos free of embedded collage captions, and body text at least 14px on mobile. Use one H1 per page, H2 for section titles and H3 for product titles. Add descriptive image alt text. The dark reference toolbar and this build guide are handoff material; omit them from the finished website.

This is a visual design reference, not an importable Elementor template. It uses plain sections, headings, images and links so you can recreate the layout manually.
